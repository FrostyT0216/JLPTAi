# 数据导出 / 导入教程

本应用的所有练习数据（练习记录、试卷缓存、未完成草稿）都保存在浏览器本机的 localStorage 中。换设备、换浏览器或清除浏览器数据前，建议先导出一份备份。

> **说明**：导出内容 **不包含 API 配置**（API 地址、API Key、模型等）。API 配置涉及密钥安全，需要在新设备上手动重新填写。

---

## 一、导出数据到本地

1. 打开应用，点击底部标签栏的 **「设置」**。
2. 找到 **「数据管理」** 分区。
3. 点击 **「导出数据到本地」**。
4. 浏览器会自动下载一个 JSON 备份文件，文件名格式为：

   ```
   jlpt-reading-backup-YYYYMMDD.json
   ```

   例如：`jlpt-reading-backup-20260830.json`。

5. 将该文件妥善保存（发送到手机、存网盘、拷贝 U 盘均可）。

**导出内容包括：**

| 数据 | 说明 |
| --- | --- |
| 练习记录 | 全部历史成绩（记录页的统计、热力图来源） |
| 试卷缓存 | 最近 20 套已完成试卷（用于回看解析） |
| 未完成草稿 | 未提交的进行中练习（如有） |

---

## 二、从本地导入数据

1. 打开应用，进入 **「设置」→「数据管理」**。
2. 点击 **「从本地导入数据」**。
3. 在弹出的文件选择框中，选中之前导出的 `jlpt-reading-backup-*.json` 文件。
4. 应用会显示备份摘要（包含多少条记录、多少套试卷），并让你选择导入方式：

   | 方式 | 效果 |
   | --- | --- |
   | **合并**（推荐） | 保留现有数据，把备份中 *没有的* 记录追加进来，自动按 ID 去重 |
   | **覆盖导入** | 先清空现有练习数据，再完整导入备份内容 |

   > 两种方式都 **不会改动 API 配置**。

5. 导入成功后会弹出提示，首页热力图、记录页统计会立即更新。

---

## 三、常见问题

### 1. 导入时提示「文件格式不正确」

- 请确认选择的是 **本应用导出的 JSON 文件**，而不是其他文件。
- 检查文件扩展名是否为 `.json`，且文件内容未被编辑器修改损坏。

### 2. 导入后部分记录没出现

- 「合并」模式按记录 ID 去重，两端已有的相同记录只保留一份，这是正常现象。
- 试卷缓存最多保留最近 20 套，超出部分会被丢弃。

### 3. 换新手机/新浏览器如何迁移？

1. 旧设备：**设置 → 数据管理 → 导出数据到本地**。
2. 把备份文件传到新设备（微信/AirDrop/网盘均可）。
3. 新设备：打开应用 → **设置 → 数据管理 → 从本地导入数据** → 选择备份文件 → **合并**。
4. 手动重新填写 API 配置（服务商、API 地址、API Key、模型）。

### 4. 导出的文件安全吗？

- 备份文件 **不含 API Key**，泄露风险低，但包含你的练习历史，建议不要公开分享。
- 所有操作均在本地完成，数据不会上传到任何服务器。

### 5. iOS 添加到主屏幕（PWA）后如何导出？

- 在 PWA 全屏模式下点击导出后，文件会通过系统分享/下载菜单给出；如无反应，可改用 Safari 打开应用后执行导出。
